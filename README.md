# VeriMatch AI — AI-Powered Resume Analyzer & Job Matching Platform

VeriMatch AI is an intelligent resume analysis, trust verification, and precision job matching platform built with **React**, **Vite**, and **Tailwind CSS**.

---

## 🚀 Features

### 🌟 Landing Page
- Modern 2-column layout with ambient light theme.
- Interactive robot animation with edge blending and soft glow.
- 4 floating glass-style metric cards ("Analyze Resume", "Match with Jobs", "Get Recommendations", "92% Match Score").
- Smooth scrolling navigation (About, Sign in, Contact).
- 1-Click demo authentication pre-loaded with sample engineer credentials (*Sarah Chen*).

### 🎛️ Intelligence Modules (All 22 Active)
1. **Resume Upload & Parsing**: Extract structured profile data from PDF/DOCX.
2. **Job Matching**: Explainable score split (50% Skills, 25% Experience, 25% Projects).
3. **Job Description Input**: Paste text/URL and rank against open benchmark roles.
4. **Resume Improvement**: Targeted suggestions and side-by-side Before/After diff viewer.
5. **Hidden Skills Interview**: Conversational AI probing for unlisted skills.
6. **Experience Translator**: Convert non-traditional experience into standard competencies.
7. **Skill Freshness**: Trajectory analysis weighting recency and market demand.
8. **Claims vs. Evidence**: Transparent proof badges (Proven, Demonstrated, Weak, Missing).
9. **Verified Match**: 5-minute algorithmic challenge with follow-up question.
10. **Skill Badges**: Three-tier cryptographic verification passport.
11. **Anti-Cheat Signals**: Non-invasive soft signal telemetry (seeds, time caps, paste pacing).
12. **Recruiter Re-Verify**: 2-minute live verbal follow-up screening prompts.
13. **Advocate vs. Skeptic Debate**: Dual AI agents deliberating candidate fit.
14. **What-If Simulator**: Instant in-code score recalculation for hypothetical skills.
15. **Recruiter's 6-Second View**: Eye-tracking heatmap and raw ATS token parser view.
16. **Adjacent Careers**: Skill map identifying roles you are ~70%+ ready for.
17. **Gap-to-Hired Plan**: 7-day tactical execution schedule with micro-projects.
18. **Job Posting Decoder**: Distinguish must-haves from wish-lists and flag unrealistic requirements.
19. **Resume-Based Mock Interview**: Targeted questions on weakest spots with AI rubric scoring.
20. **Bias Mirror**: Blind evaluation parity benchmark and inclusive language audit.
21. **Privacy Controls**: PII scrubbing, zero-retention local processing, right to erasure.
22. **Skill Gap Learning Roadmap**: Prioritized gaps with curated free resources and proof projects.

## 🛠️ Tech Stack
- **Framework**: React 18 + Vite
- **Styling**: Tailwind CSS (Custom Blue & White design system)
- **Icons**: Lucide React
- **Typography**: Plus Jakarta Sans (Headings) & Inter (Body)
